## 🛠 How to Use

1. **Follow the order** — Each day builds on previous concepts
2. **Read the notes** — Understand the theory and approach first
3. **Code the solutions** — Each folder has complete Java programs
4. **Practice on LeetCode/GFG** — Links provided in each day's README
5. **Revise regularly** — Revisit previous days while progressing

## 📝 Language

All programs are written in **Java** with detailed comments explaining the approach, time complexity, and space complexity.
