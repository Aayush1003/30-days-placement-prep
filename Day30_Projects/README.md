## 📝 Project Presentation Template

### How to Describe a Project (3-10 minutes)

Use the **STAR Framework**:

1. **Situation**: What problem were you solving? What was the context?
2. **Task**: What was your specific role and responsibility?
3. **Action**: What did you do? What technologies did you use and why?
4. **Result**: What was the outcome? Any metrics or improvements?

### Key Points to Prepare for Each Project:

```
□ One-line summary of the project
□ Problem statement — Why did you build it?
□ Tech stack — What technologies and why?
□ Architecture — High-level system design
□ Your specific contribution — What did YOU do?
□ Challenges faced — How did you solve them?
□ Key learnings — What did you learn?
□ Future improvements — What would you do differently?
```

### Sample Project Pitch Template:
```
"I built [PROJECT NAME], a [brief description] that [solves what problem].

The tech stack includes [frontend], [backend], [database], and [other tools].

My key contributions were:
1. [Feature/Module 1] — [brief explanation]
2. [Feature/Module 2] — [brief explanation]

One major challenge was [challenge], which I resolved by [solution].

The impact was [metric/result], and I learned [key learning]."
```

## 🤝 HR Interview Questions & Tips

### Tell Me About Yourself (60-90 seconds)
```
Structure: Present → Past → Future

"Hi, I'm [Name], a [Year] student at [College] studying [Branch].

I'm passionate about [area — e.g., full-stack development / algorithms].
I've built projects like [Project 1] using [tech] and [Project 2].

I've also worked on [internship/experience] where I [key achievement].

I'm now looking forward to [what you want — growth, contributing to team]."
```

### Common HR Questions:

| Question | Tip |
|----------|-----|
| Why should we hire you? | Match your skills to their JD |
| Strengths & Weaknesses | Genuine + show improvement for weakness |
| Where do you see yourself in 5 years? | Growth in technical expertise |
| Why this company? | Research company values, products, culture |
| Conflict with team? | Show resolution skills, not blame |
| Biggest achievement? | Use STAR framework |
| Why gap/low grades? | Be honest, show what you did instead |

### Questions to Ask the Interviewer:
1. What does a typical day look like for this role?
2. What tech stack does the team use?
3. How is mentorship structured for new hires?
4. What are the biggest challenges the team is facing?
5. What growth opportunities are available?
